# pastilishop

یک فروشگاه پاستیلی مدرن و فارسی با رابط راست‌به‌چپ، سبد خرید، پنل ادمین نمایشی و طراحی نئونی.

## اجرا

کافی است فایل `index.html` را در مرورگر باز کنید یا با یک سرور ساده اجرا کنید:

```bash
python3 -m http.server 5173 --bind 0.0.0.0
```

سپس آدرس سرور را باز کنید.
